# Reference Reels

Reels saved purely as **references** for scripting, editing and shooting our own videos later.
Nothing here is for publishing, only for study.

## How to use
- Add each reel link to `reels.md` (one row per reel).
- Optional: drop downloaded video files in `downloads/` (name them to match the ID in `reels.md`).
- For each reel, fill in the notes: hook, structure, editing style, audio, what to borrow.

## Structure
- `reels.md`: index of all reference reels + breakdown notes
- `downloads/`: video files / transcripts / screenshots (if any)
